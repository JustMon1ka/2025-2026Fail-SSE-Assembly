# 一、除零中断与溢出中断的基本概念（第 1 问）

## 除零中断（Divide Error）

### 含义

在执行 **除法指令** 时：

* 除数为 **0**
* 或者 **商超出目标寄存器可表示范围**

CPU 无法给出合法结果，于是触发异常。

### x86 中的表现

* 对应异常向量号：**0 号中断**
* 常称为：`#DE (Divide Error)`

注意：
**并非只有“除数为 0”才触发**，商溢出同样会触发除零异常。

---

## 溢出中断（Overflow）

### 含义

* 执行算术运算（加、减、乘）后
* 结果超出**有符号数表示范围**
* 并且 **显式执行 `INTO` 指令**

### x86 中的表现

* 对应异常向量号：**4 号中断**
* 常称为：`#OF (Overflow)`

关键点：

> **溢出并不会自动触发中断，必须执行 `INTO`**

---

# 二、硬件层面的处理（第 2 问）

## CPU 对异常的统一处理流程

当发生除零或溢出异常时，CPU 会：

1. **立即停止当前指令执行**
2. 保存当前状态：

   * CS、IP
   * FLAGS
3. 查 **中断向量表（IVT）**
4. 跳转到对应异常处理程序

---

## 硬件层面对两种异常的区别

| 异常   | 触发时机            | 是否自动    |
| ---- | --------------- | ------- |
| 除零异常 | 执行 `DIV / IDIV` | 自动    |
| 溢出异常 | 执行 `INTO`       | 需程序显式 |

### FLAGS 寄存器中的相关位

| 标志位 | 作用    |
| --- | ----- |
| OF  | 溢出标志  |
| CF  | 无符号溢出 |

---

## 硬件层的特点总结

* CPU **只负责发现异常**
* 不关心：

  * 程序逻辑
  * 错误是否可恢复
* 处理方式 **完全由中断向量决定**

---

# 三、操作系统层的处理（第 3 问）

操作系统是 **异常的真正管理者**。

---

## 操作系统在异常中的角色

当 CPU 进入异常中断后：

1. 转入 **OS 内核态异常处理程序**
2. OS 判断异常来源：

   * 用户态？
   * 内核态？
3. 决定后续动作

---

## 操作系统对除零异常的处理

### 常见策略（以现代 OS 为例）

| 情况   | 处理方式         |
| ---- | ------------ |
| 用户程序 | 发送异常信号并终止    |
| 内核程序 | 系统 panic 或崩溃 |

### Linux 示例

* 除零异常 → `SIGFPE`
* 默认行为：终止进程

---

## 操作系统对溢出异常的处理

* 很多系统 **不主动使用硬件溢出异常**
* 溢出多在：

  * 编译期检查
  * 运行时库
  * 软件逻辑层处理

因此：

> **#OF 在现代 OS 中使用频率很低**

---

## OS 层特点总结

* 异常 = **受控的程序错误**
* OS 决定：

  * 是否杀进程
  * 是否生成错误信息
* OS 为语言运行时提供“安全边界”

---

# 四、语言层的处理（第 4 问）

这一层是**用户最直观感受到的**。

---

## C 语言

### 除零

* **整数除零**：未定义行为（通常触发硬件异常）
* **浮点除零**：返回 `inf` 或 `NaN`

### 溢出

* **有符号整数溢出**：未定义行为
* **无符号溢出**：自动取模

特点：

> C 语言几乎不做保护，极度贴近硬件

---

## Java

### 除零

* 整数除零：抛出 `ArithmeticException`
* 浮点除零：返回 `Infinity / NaN`

### 溢出

* 整数溢出：**自动回绕，不抛异常**

Java 选择：

> 用异常处理“致命错误”，性能优先

---

## Python

### 除零

* 直接抛出 `ZeroDivisionError`

### 溢出

* 整数：**自动扩展为大整数**
* 浮点：`inf / OverflowError`

Python 目标：

> 安全性和正确性优先于性能

---

## 三种语言对比总结

| 语言     | 除零  | 溢出   | 特点   |
| ------ | --- | ---- | ---- |
| C      | 未定义 | 未定义  | 靠程序员 |
| Java   | 异常  | 回绕   | 平衡性能 |
| Python | 异常  | 自动扩展 | 安全优先 |
