# 一、段内跳转 vs 段间跳转（第 1 点）

## 段内跳转（near jump / near call）

之前作业里用到的：

* `JMP label`
* `JZ / JNZ / LOOP`
* `CALL proc`

**本质特征：**

* **CS 不变**
* **只修改 IP**
* 跳转目标在**当前代码段内**

### CPU 实际行为

```text
CS = 原值
IP = 新偏移
```

这是为什么单步调试时看到：

> IP 在跳，但 CS 一直不变

---

## 段间跳转（far jump / far call）

**段间跳转的本质：**

> **同时修改 CS 和 IP**

```text
CS = 新段值
IP = 新偏移
```

这才是真正意义上的“跨代码段执行”。

---

# 二、同一源文件中，多个代码段之间跳转（第 2 点）

## 代码结构示例（单文件，多代码段）

```asm
.MODEL SMALL
.STACK 100H

.CODE
CODE1 SEGMENT
ASSUME CS:CODE1

START:
    CALL FAR PTR PROC2     ; 段间调用
    JMP  $

CODE1 ENDS

CODE2 SEGMENT
ASSUME CS:CODE2

PROC2 PROC FAR
    MOV AX, 1234H
    RETF                  ; 段间返回
PROC2 ENDP

CODE2 ENDS

END START
```

---

## 单步调试时会看到什么

### 执行 `CALL FAR PTR PROC2`

| 时刻  | CS    | IP           |
| --- | ----- | ------------ |
| 调用前 | CODE1 | START+offset |
| 调用后 | CODE2 | PROC2        |

**CS 和 IP 同时变化**

---

### 执行 `RETF`

| 时刻  | CS    | IP     |
| --- | ----- | ------ |
| 返回前 | CODE2 | PROC2+ |
| 返回后 | CODE1 | 调用点后   |

FAR CALL / RETF **成对出现**，否则栈会错乱。

---

## 与段内调用的对比（非常重要）

| 类型 | CALL     | RET  |
| -- | -------- | ---- |
| 段内 | CALL     | RET  |
| 段间 | CALL FAR | RETF |

---

# 三、拆分为多个源文件后再链接（第 3 点）

---

## 拆分示例

### 文件 1：`main.asm`

```asm
.MODEL SMALL
.STACK 100H

.CODE
EXTRN PROC2:FAR

START:
    CALL PROC2
    JMP $

END START
```

---

### 文件 2：`proc2.asm`

```asm
.MODEL SMALL

.CODE
PUBLIC PROC2

PROC2 PROC FAR
    MOV AX, 5678H
    RETF
PROC2 ENDP

END
```

---

## 汇编 + 链接后的本质变化

* **每个 .asm 文件 → 独立的代码段**
* 链接器：

  * 为每个段分配段地址
  * 自动生成 **far call 的 CS:IP**

---

## 单步调试时 CS:IP 的变化

执行 `CALL PROC2` 时：

```text
CS:IP  → main.asm 的代码段
↓
CS:IP  → proc2.asm 的代码段
```

返回时再切回。

**即使没写 FAR，链接器也会强制生成 FAR CALL**

# 四、无条件跳转指令 jmp 可以跨段吗？（第 4 点）

> **可以，但必须是 FAR JMP，普通 JMP 不行。**

---

## 普通 JMP（段内）

```asm
JMP LABEL
```

* 编码里 **只有 IP**
* **不能修改 CS**
* 不能跨段

---

## 段间 JMP（FAR JMP）

```asm
JMP FAR PTR TARGET
```

或（显式给出）：

```asm
JMP DWORD PTR SEGMENT:OFFSET
```

### CPU 行为

```text
CS ← 新段值
IP ← 新偏移
```

---

## FAR JMP 的特点

* 不压栈
* 不可返回
* 一般用于：

  * 启动代码
  * 特权切换
  * 跳转到完全不同模块

---

## JMP vs CALL 跨段能力对比

| 指令   | 可跨段    | 是否返回    |
| ---- | ------ | ------- |
| JMP  | （FAR） |    x   |
| CALL | FAR） | （RETF） |
