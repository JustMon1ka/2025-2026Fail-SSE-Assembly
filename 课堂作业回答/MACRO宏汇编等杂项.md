# 一、MACRO 宏汇编 vs PROC 过程（第 1 点）

## 1.1 用 MACRO 改写之前的过程，并观察区别

### PROC（过程）的本质

以之前常见的过程为例：

```asm
PrintChar PROC
    MOV AH, 0EH
    INT 10H
    RET
PrintChar ENDP
```

调用时：

```asm
CALL PrintChar
```

### 汇编后的特点

* **代码只存在一份**
* `CALL` 会：

  * 压栈返回地址
  * 跳转执行
* `RET` 再返回

单步调试时能看到：

* 栈变化
* CS:IP 跳转再返回

---

### MACRO（宏）的本质

改成宏写法：

```asm
PrintChar MACRO
    MOV AH, 0EH
    INT 10H
ENDM
```

使用时：

```asm
PrintChar
```

### 汇编后的真实情况

> **宏在汇编阶段直接展开**

等价于手写：

```asm
MOV AH, 0EH
INT 10H
```

汇编后：

* **没有 CALL**
* **没有 RET**
* **没有栈变化**
* 单步执行时就是顺序执行

---

### 汇编后两种形式的直观区别

| 对比项       | PROC | MACRO |
| --------- | ---- | ----- |
| 是否生成 CALL | √    | x     |
| 是否有 RET   | √     | x    |
| 是否使用栈     | √     | x     |
| 代码体积      | 小    | 可能变大  |
| 执行效率      | 稍低   | 高     |

---

## 1.2 什么时候用 PROC？什么时候用 MACRO？

### 适合用 PROC 的情况

* 代码**较大**
* 被**多次调用**
* 逻辑明确、模块化
* 需要：

  * 递归
  * 返回值
  * 节省代码空间

**子程序 / 功能模块**

---

### 适合用 MACRO 的情况

* 代码**很短**
* 对性能敏感
* 不希望：

  * 压栈
  * 跳转
* 需要“模板式”代码

**指令级封装 / 语法糖**

# 二、字符串处理指令（第 2 点）

##  字符串指令的共同特点

* 使用 **SI / DI**
* 使用 **DS:SI、ES:DI**
* 可配合：

  * `REP`
  * `REPZ / REPNZ`
* 自动修改 SI / DI

---

## 常见字符串指令分类

### 1）数据传送类

```asm
MOVSB    ; 字节
MOVSW    ; 字
```

等价于：

```asm
MOV AL, [SI]
MOV [DI], AL
INC SI
INC DI
```

---

### 2）比较类

```asm
CMPSB
CMPSW
```

* 自动比较 `[SI]` 和 `[DI]`
* 修改标志位

---

### 3）扫描类

```asm
SCASB
```

* 用 AL 与 `[DI]` 比较
* 常用于查找字符

---

### 4）装载类

```asm
LODSB
```

* `[SI] → AL`

---

### 5）存储类

```asm
STOSB
```

* `AL → [DI]`

---

##  REP 前缀的作用

```asm
REP MOVSB
```

含义：

* 重复执行
* 次数由 `CX` 决定

**这是字符串指令效率高的核心原因**

---

## 字符串指令的实验意义

* 体现：

  * **硬件级循环**
  * **指针自动更新**
* 是后续：

  * memcpy
  * strcmp
  * strlen
    的底层基础

---

# 三、IN / OUT 指令的学习与实践（第 3 点）

##  IN 指令

```asm
IN AL, 60H
```

含义：

* 从 I/O 端口 `60H` 读数据
* 存入 AL

---

## OUT 指令

```asm
OUT 61H, AL
```

含义：

* 把 AL 写到 I/O 端口

---

## IN / OUT 的使用场景

* 键盘控制器（端口 60H）
* 显示适配器
* 定时器
* 并口 / 串口

在 DOS / BIOS 实验中：

> **IN / OUT 是绕过 BIOS，直接和硬件通信**

---

## 使用限制

* 属于 **特权相关指令**
* 在现代 OS 下：

  * 用户态 x
  * 内核态 √
* 在 DOSBox / 实模式下可用

---

## 与 BIOS 中断的关系

| 方式            | 层次   |
| ------------- | ---- |
| IN / OUT      | 硬件级  |
| int 10h / 16h | BIOS |
| int 21h       | OS   |
